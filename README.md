# Kernel com KernelSU pro Moto G62 5G + pedidos da galera 🇧🇷

Kernel com **KernelSU (v3.3.0)** e build automática na nuvem (GitHub Actions).

✅ Hoje: **Moto G62 5G (rhodei) — Snapdragon 480+ — Kernel 5.4**
🚀 Outro celular? Abre uma Issue que eu olho!

## Como pedir suporte

1. `Issues > New issue > Pedido de Suporte para Novo Dispositivo`
2. Manda: nome do aparelho, codinome, chipset, versão do Android + link do `boot.img` original
3. Eu adapto o código e solto a build aqui

Sem o `boot.img` original não tem como começar.

## Builds

Tudo compila no Linux da nuvem: `Actions > Build Kernel rhodei + KernelSU > Artifacts > Image.gz`

⚠️ Desbloquear o bootloader é por tua conta (apaga tudo, perde garantia). Guarda teu `boot.img` original.
