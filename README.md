# KernelSU for Moto G62 5G + Comunidade Sob Demanda 🇧🇷🇺🇸

> PT: Projeto comunitário para trazer **KernelSU (v3.3.0)** e módulos customizados com build automática na nuvem (GitHub Actions).
> EN: Community project bringing **KernelSU (v3.3.0)** and custom modules with automatic cloud builds (GitHub Actions).

✅ Suportado hoje: **Motorola Moto G62 5G (rhodei) — Snapdragon 480+ — Kernel 5.4**
🚀 Quer outro celular? Abre uma Issue!

## PT — Como pedir suporte
1. Vá em `Issues > New issue > Pedido de Suporte para Novo Dispositivo`
2. Preencha: Nome comercial, Codinome, Chipset, Versão Android + link do `boot.img` Stock
3. Eu analiso, adapto o código e libero a build aqui mesmo

Sem `boot.img` original eu não consigo começar.

## EN — How to request support
1. Go to `Issues > New issue > Device Support Request`
2. Fill: Commercial name, Codename, Chipset, Android version + Stock `boot.img` link
3. I review, adapt the code and release the build here

Without the original `boot.img` I can't start.

## Builds
Toda compilação é externa Linux: `Actions > Build Kernel rhodei + KernelSU > Artifacts > Image.gz-dtb`
Every build runs on Linux cloud: `Actions > Build Kernel rhodei + KernelSU > Artifacts > Image.gz-dtb`

⚠️ Desbloqueie o bootloader por sua conta e risco. Faça backup do `boot.img`.
⚠️ Unlock bootloader at your own risk. Backup your `boot.img`.
